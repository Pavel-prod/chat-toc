# chat-toc — оглавление чата для Claude Code

Мод для Claude Code. В терминале открывает рядом с чатом панель «Оглавление»: после каждого твоего вопроса в ней появляется пункт с короткой темой (её формулирует модель Haiku по вопросу и началу ответа), а клик по пункту прокручивает чат к ответу. В десктопном приложении Claude панель сама не открывается: там лента чата не прокручивается из модов, а кликабельное оглавление даёт встроенный список «Session chapters» (иконка ≡ слева вверху ленты). Команда `/toc` открывает панель вручную где угодно.

## Установка

В терминальной сессии Claude Code, в строке ввода:

```
/plugin install chat-toc --marketplace Pavel-prod/chat-toc
```

Дальше: `y` на вопрос «Add marketplace?», затем выбрать область установки (первая — user, для всех проектов).

Из обычной командной строки:

```
claude plugin install chat-toc --marketplace Pavel-prod/chat-toc
```

В десктопном приложении Claude, где `/plugin` не работает: нажать «+» рядом с полем ввода → Plugins → Add marketplace, ввести `Pavel-prod/chat-toc`, затем Add plugin.

## Как устроено

- `hooks/register.tsx` — модуль хуков: ловит вопрос человека, каждый блок ответа модели и конец хода, хранит список в состоянии сессии, рисует панель.
- `types/index.d.ts` — контракт хранимых значений.
- Заголовок пункта формулирует быстрая модель (`haiku`) одним коротким запросом после каждого ответа; при ошибке остаётся обрезанный текст вопроса.
